# PPT作成支援エージェント

## 概要
大規模企業の企業内ナレッジを活用した、ブランド準拠のPowerPoint自動生成エージェント。
ユーザーが要件を入力すると、既定のテンプレートに従った高品質なスライドを自動生成します。

## 背景・課題
- 企業ブランドガイドに準拠したスライド作成に時間がかかる
- スライドテンプレートの統一化が進まない
- 各部門で独自フォーマットが乱立している

## ソリューション
**Copilot Studio** + **Power Platform** による自動化エージェント

### システム構成
ユーザー入力
↓
Copilot Agent（要件解析）
↓
Dataverse（テンプレート・ブランド情報）
↓
PowerPoint生成
↓
出力

## 技術スタック

- **Copilot Studio**: エージェント開発・プロンプト管理
- **Power Platform**: Dataverse、PowerApps
- **Microsoft Office**: PowerPoint API
- **生成AI**: プロンプトエンジニアリング

## 実装の工夫

### 1. プロンプト設計
- ブランドガイドを Copilot に学習させるプロンプト構造
- 階層的な指示文で一貫性を担保
- エラーハンドリング（不正な入力への対応）

### 2. テンプレート管理
- ブランド要素（色・フォント・ロゴ等）を Dataverse に一元管理
- ユーザーが追加変更できる仕組み
- バージョン管理による更新追跡

### 3. 品質控除（Quality Gate）
- 生成後の自動検証ロジック
- ガイドライン違反の検出
- 手動レビュー申請の自動ルーティング

## 成果・学習ポイント
### 導入効果
- スライド作成時間：３～５時間 → １時間程度に短縮
- ブランド準拠率：ほぼ１００% 向上
- 利用者満足度：実装後のアンケートで高評価

### 技術的な学習
- **Copilot Studioの実装パターン**
  - 複数トピックの組み合わせ
  - エラーハンドリングの実装

- **プロンプトエンジニアリング**
  - 企業知識の効率的な組み込み
  - トーン・スタイルの制御

- **Power Platform の連携**
  - Dataverse のデータ取得・更新ロジック
  - 他のシステムとの連携設計
